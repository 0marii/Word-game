# Wordle Game

A browser-based clone of the classic **Wordle** game built with HTML, CSS, and JavaScript. Guess the hidden five-letter word in six attempts with color-coded feedback for each guess.

## 🎮 Live Demo

👉 https://0marii.github.io/Wordle-game/

## ✨ Features

- 🟩 Classic Wordle gameplay
- 🎨 Color-coded letter feedback
- ⌨️ Interactive on-screen keyboard
- 📱 Responsive design for desktop and mobile
- ⚡ Fast and lightweight with no dependencies

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/0marii/Wordle-game.git
   ```

2. Open `index.html` in your browser.
